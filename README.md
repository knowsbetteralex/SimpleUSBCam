# SimpleUSBCam

Небольшое Android-приложение для USB-эндоскопа (UVC), в частности **VID 349C / PID 0411**.

**Тестовая версия 0.4.0:** исправление ошибочной 90-градусной ротации NV21 перед H.264-кодированием в портретном режиме AUSBC, полноэкранное UVC-превью с быстрым программным выводом NV21 без промежуточного JPEG, переключение программного и аппаратного предпросмотра, отображение FPS USB/экрана, подсчёт реальных видеокадров, YUYV по умолчанию с выбором наибольшего заявленного YUYV-разрешения и автоматическим возвратом к 640×480 при отсутствии кадров, переключаемый формат MJPEG/YUYV, фотографии, MP4-видео со звуком встроенного микрофона телефона, мигающий индикатор REC при фактически начавшейся записи, автоматический ландшафтный интерфейс при повороте устройства без перезапуска USB-потока, автоподключение и системный USB-автозапуск при вставке камеры, живой индикатор уровня звука (до записи — PCM с микрофона; во время записи — декодирование копии AAC-пакетов), поворот картинки, переключатель микрофона. Физическая кнопка эндоскопа пока поддерживается как Android camera key; нативный UVC callback временно отключён до отдельного тестирования.

## Запуск

1. Установить APK из последнего успешного [релиза](https://github.com/knowsbetteralex/SimpleUSBCam/releases/latest) (если релиз ещё не опубликован, смотреть вкладку [Actions](https://github.com/knowsbetteralex/SimpleUSBCam/actions)).
2. Подключить эндоскоп USB-C (OTG), разрешить приложению доступ к USB-камере, микрофону и камере Android. Android при первом подключении предложит выбрать приложение. Выберите SimpleUSBCam и при желании назначьте приложением по умолчанию для этого USB-устройства; после этого приложение будет запускаться по подключению, насколько разрешает система.
3. Нажать **Фото** или **Запись**. При записи звук берётся именно с телефона.
4. Переключатель **Микрофон** можно менять до начала записи. Для применения к записи переподключить эндоскоп; во время записи переключение блокируется.
5. По умолчанию выбран **YUYV авто (макс.)**: после первого открытия AUSBC запрашивает наибольшее разрешение из списка YUYV; при отсутствии кадров возвращается на рабочие 640×480. Если изображение не появляется, нажать на строку USB для копирования диагностики. Счётчик «кадров» должен увеличиваться. Для ручного выбора формата используйте **YUYV / MJPEG** и переподключите камеру. USB-кнопка остаётся резервным ручным повтором запроса, но обычно её нажимать не нужно.
6. Поворот телефона при включённом системном автоповороте меняет портретную и ландшафтную компоновку интерфейса без уничтожения TextureView. Индикатор **● REC** мигает только после запуска MP4-мультиплексора и исчезает после остановки.\n7. В строке USB показаны **FPS USB / FPS экрана**. Кнопка **ПРОГ / АПП** переключает программный и аппаратный предпросмотр без переподключения; если в АПП экран чёрный, вернуть ПРОГ. В аппаратном режиме FPS экрана обозначается `-1`, поскольку счётчик отрисовки программных Bitmap отключён.
8. После записи MP4 или фотографии приложение переносит файл из внутреннего каталога AUSBC в системную галерею через **MediaStore**. Видео: `Movies/SimpleUSBCam`, фотографии: `Pictures/SimpleUSBCam`. На Android 6–9 требуется разрешение записи в память; если перенос не удался, исходный файл остаётся в папке приложения и показывается сообщение об ошибке.

## Технологии

- Java, Android API 23+, compileSdk 36, targetSdk 34.
- [AUSBC / AndroidUSBCamera](https://github.com/ernestp/AndroidUSBCamera), версия **3.6.0**, Apache-2.0. Работа с UVC (включая изохронные USB-потоки), MediaCodec, MP4.
- AudioRecord для уровня звука в режиме ожидания; AAC/MediaCodec-декодер для уровня звука во время записи **без второго захвата микрофона**.
- Сборка GitHub Actions (debug APK, подписан тестовым ключом сборки). Для реального релиза понадобится постоянный ключ подписи.

## Исправление записи MP4 (0.3.1)

На телефоне в портретной ориентации библиотека AUSBC 3.6.0 передавала в H.264-кодер повёрнутый на 90° буфер NV21 **без обмена ширины и высоты**, что приводило к горизонтальному дублированию кадра, артефактам и полосам. Для `RenderMode.NORMAL` приложение теперь отключает ошибочный поворот `H264EncodeProcessor.isPortrait` перед записью; геометрия и фактический порядок байтов должны совпадать. Файл MP4 сохраняется в исходной ориентации камеры (640×480 или 320×240). Если структура AUSBC изменится, запись будет заблокирована и в диагностике появится `H264 geometry fix: FAILED`, чтобы избежать повреждённых файлов.

Остальные маршруты, в том числе YUYV-превью, фотосъёмка, запись микрофона и сохранение в галерею, не изменялись.

## Проверки на физическом устройстве

- Изображение с `349c:0411` в MJPEG или YUYV. `UVC OPEN` не означает, что кадры идут: проверить счётчик кадров.
- На работающем YUYV-потоке записать MP4 5–10 секунд в портретном положении, проверить отсутствие повторяющихся колонок/полос и звук. Для этой версии картинка в MP4 остаётся горизонтальной, как у эндоскопа.
- Кнопка на кабеле: нативный обработчик UVC временно отключён до устранения проблем потока; Android KEYCODE_CAMERA остаётся запасным вариантом.
- Поведение при отсоединении кабеля и отказах в разрешениях; автозапуск при USB-подключении (первый раз может потребоваться системное подтверждение), автоматическое подключение без ручного USB.
- Проверить галерею / MediaStore и отображение медиа в системном приложении на конкретном телефоне (Android 10+).

### Ограничения первой версии

- Запись работает только пока приложение открыто; при сворачивании запись останавливается для корректной финализации MP4.
- Индикатор во время записи зависит от поддержки декодирования AAC 8 кГц на устройстве. Отказ декодера не влияет на сохранение звука, но индикатор будет недоступен.
- Кнопка в Inskam работает; UVC callback отложен до подтверждения стабильного видео.\n- Максимальное YUYV разрешение может работать медленнее, чем 640×480; fallback выполняется только при отсутствии кадров, а не при низком FPS.\n- Скорость, показанная USB FPS, зависит от аппаратной камеры, выбранного разрешения, USB-транспорта и телефона. Программный RGB-просмотр ограничен максимумом 30 FPS, но не гарантирует эту скорость.
