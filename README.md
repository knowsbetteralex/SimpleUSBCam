# SimpleUSBCam

Небольшое Android-приложение для USB-эндоскопа (UVC), в частности **VID 349C / PID 0411**.

**Тестовая версия 0.2.0:** полноэкранное UVC-превью с программным резервным выводом NV21, подсчёт реальных видеокадров, переключаемый формат MJPEG/YUYV и размер кадра, фотографии, MP4-видео со звуком встроенного микрофона телефона, живой индикатор уровня звука (до записи — PCM с микрофона; во время записи — декодирование копии AAC-пакетов), поворот картинки, переключатель микрофона. Обрабатываем UVC-кнопку через нативный callback AUSBC и дополнительно Android-события кнопки камеры; работу на конкретном устройстве нужно проверить.

## Запуск

1. Установить APK из последнего успешного [релиза](https://github.com/knowsbetteralex/SimpleUSBCam/releases/latest) (если релиз ещё не опубликован, смотреть вкладку [Actions](https://github.com/knowsbetteralex/SimpleUSBCam/actions)).
2. Подключить эндоскоп USB-C (OTG), разрешить приложению доступ к USB-камере, микрофону и камере Android.
3. Нажать **Фото** или **Запись**. При записи звук берётся именно с телефона.
4. Переключатель **Микрофон** можно менять до начала записи. Для применения к записи переподключить эндоскоп; во время записи переключение блокируется.
5. Если изображение не появляется, нажать на строку USB для копирования диагностики. Счётчик «кадров» должен увеличиваться. Нажать кнопку **MJPEG / YUYV**, выбрать альтернативный формат и переподключить эндоскоп. Запись недоступна до поступления реальных видеокадров.\n6. После успешной записи проверить MP4, включая синхронизацию звука; файлы сохраняются в каталог приложения AUSBC (состояние системной галереи зависит от Android).

## Технологии

- Java, Android API 23+, compileSdk 36, targetSdk 34.
- [AUSBC / AndroidUSBCamera](https://github.com/ernestp/AndroidUSBCamera), версия **3.6.0**, Apache-2.0. Работа с UVC (включая изохронные USB-потоки), MediaCodec, MP4.
- AudioRecord для уровня звука в режиме ожидания; AAC/MediaCodec-декодер для уровня звука во время записи **без второго захвата микрофона**.
- Сборка GitHub Actions (debug APK, подписан тестовым ключом сборки). Для реального релиза понадобится постоянный ключ подписи.

## Проверки на физическом устройстве

- Изображение с `349c:0411` в MJPEG или YUYV. `UVC OPEN` не означает, что кадры идут: проверить счётчик кадров.
- Наличие звука в MP4 и показания измерителя *во время* записи.
- Кнопка на кабеле: нативный обработчик UVC временно отключён до устранения проблем потока; Android KEYCODE_CAMERA остаётся запасным вариантом.
- Поведение при отсоединении кабеля и отказах в разрешениях.
- Галерея / MediaStore для конкретного телефона и версии Android.

### Ограничения первой версии

- Запись работает только пока приложение открыто; при сворачивании запись останавливается для корректной финализации MP4.
- Индикатор во время записи зависит от поддержки декодирования AAC 8 кГц на устройстве. Отказ декодера не влияет на сохранение звука, но индикатор будет недоступен.
- Кнопка в Inskam работает; UVC callback отложен до подтверждения стабильного видео.
