# SimpleUSBCam

Небольшое Android-приложение для USB-эндоскопа (UVC), в частности **VID 349C / PID 0411**.

**Тестовая версия 0.3.0:** полноэкранное UVC-превью с быстрым программным выводом NV21 без промежуточного JPEG, переключение программного и аппаратного предпросмотра, отображение FPS USB/экрана, подсчёт реальных видеокадров, переключаемый формат MJPEG/YUYV и размер кадра, фотографии, MP4-видео со звуком встроенного микрофона телефона, живой индикатор уровня звука (до записи — PCM с микрофона; во время записи — декодирование копии AAC-пакетов), поворот картинки, переключатель микрофона. Обрабатываем UVC-кнопку через нативный callback AUSBC и дополнительно Android-события кнопки камеры; работу на конкретном устройстве нужно проверить.

## Запуск

1. Установить APK из последнего успешного [релиза](https://github.com/knowsbetteralex/SimpleUSBCam/releases/latest) (если релиз ещё не опубликован, смотреть вкладку [Actions](https://github.com/knowsbetteralex/SimpleUSBCam/actions)).
2. Подключить эндоскоп USB-C (OTG), разрешить приложению доступ к USB-камере, микрофону и камере Android.
3. Нажать **Фото** или **Запись**. При записи звук берётся именно с телефона.
4. Переключатель **Микрофон** можно менять до начала записи. Для применения к записи переподключить эндоскоп; во время записи переключение блокируется.
5. Если изображение не появляется, нажать на строку USB для копирования диагностики. Счётчик «кадров» должен увеличиваться. Нажать кнопку **MJPEG / YUYV**, выбрать альтернативный формат и переподключить эндоскоп. Запись недоступна до поступления реальных видеокадров.
6. В строке USB показаны **FPS USB / FPS экрана**. Кнопка **ПРОГ / АПП** переключает программный и аппаратный предпросмотр без переподключения; если в АПП экран чёрный, вернуть ПРОГ. В аппаратном режиме FPS экрана обозначается `-1`, поскольку счётчик отрисовки программных Bitmap отключён.
7. После записи MP4 или фотографии приложение переносит файл из внутреннего каталога AUSBC в системную галерею через **MediaStore**. Видео: `Movies/SimpleUSBCam`, фотографии: `Pictures/SimpleUSBCam`. На Android 6–9 требуется разрешение записи в память; если перенос не удался, исходный файл остаётся в папке приложения и показывается сообщение об ошибке.

## Технологии

- Java, Android API 23+, compileSdk 36, targetSdk 34.
- [AUSBC / AndroidUSBCamera](https://github.com/ernestp/AndroidUSBCamera), версия **3.6.0**, Apache-2.0. Работа с UVC (включая изохронные USB-потоки), MediaCodec, MP4.
- AudioRecord для уровня звука в режиме ожидания; AAC/MediaCodec-декодер для уровня звука во время записи **без второго захвата микрофона**.
- Сборка GitHub Actions (debug APK, подписан тестовым ключом сборки). Для реального релиза понадобится постоянный ключ подписи.

## Проверки на физическом устройстве

- Изображение с `349c:0411` в MJPEG или YUYV. `UVC OPEN` не означает, что кадры идут: проверить счётчик кадров.
- Наличие звука в MP4 и показания измерителя *во время* записи.
- Кнопка на кабеле: нативный обработчик UVC временно отключён до устранения проблем потока; Android KEYCODE_CAMERA остаётся запасным вариантом.
- Поведение при отсоединении кабеля и отказах в разрешениях.
- Проверить галерею / MediaStore и отображение медиа в системном приложении на конкретном телефоне (Android 10+).

### Ограничения первой версии

- Запись работает только пока приложение открыто; при сворачивании запись останавливается для корректной финализации MP4.
- Индикатор во время записи зависит от поддержки декодирования AAC 8 кГц на устройстве. Отказ декодера не влияет на сохранение звука, но индикатор будет недоступен.
- Кнопка в Inskam работает; UVC callback отложен до подтверждения стабильного видео.\n- Скорость, показанная USB FPS, зависит от аппаратной камеры, выбранного разрешения, USB-транспорта и телефона. Программный RGB-просмотр ограничен максимумом 30 FPS, но не гарантирует эту скорость.
